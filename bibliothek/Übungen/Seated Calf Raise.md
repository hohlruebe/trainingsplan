# Seated Calf Raise

## Einordnung
- Familie: [[Calf Raise (Familie)]]

## Zweck
Wadenheben im Sitzen: trainiert den tieferen Wadenmuskel.

## Vorbereitung
Bank oder Stuhl, Fußballen auf einer Erhöhung, Gewicht auf den Knien.

## So geht’s
1. Setz dich, die Fußballen auf der Erhöhung, das Gewicht auf den Knien.
2. Heb die Fersen so hoch wie möglich.
3. Senk sie langsam ab.

## Raus
Gewicht von den Knien nehmen.

## Sauber, wenn
Die Knie bleiben etwa rechtwinklig gebeugt, die Bewegung ist vollständig.

## Technik

## Atmung
Beim Heben ausatmen.

## Häufige Fehler
- Mit den Händen abstoßen.
  → Hände nur auf das Gewicht legen.

## Leichter und schwerer
Leichter: weniger Gewicht. Schwerer: mehr Gewicht oder oben 2 Sekunden halten.

## Wann aufhören

## Trainiert
Tiefe Wadenmuskulatur
