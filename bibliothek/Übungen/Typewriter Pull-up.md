# Typewriter Pull-up

## Einordnung
- Familie: [[Pull-up (Familie)]]

## Zweck
Oben im Klimmzug von einer Hand zur anderen schieben: hohe Belastung für jeweils einen Arm, Vorstufe für einarmige Züge.

## Vorbereitung
Stange lang genug für einen breiten Griff, etwa doppelte Schulterbreite.

## So geht’s
1. Greif deutlich breiter als schulterbreit im Obergriff.
2. Zieh dich hoch, bis das Kinn über der Stange ist.
3. Schieb den Körper oben zu einer Hand, der andere Arm wird dabei gestreckt.
4. Schieb zurück durch die Mitte zur anderen Hand.
5. Kehr zur Mitte zurück und senk dich kontrolliert ab.

## Raus
Im gestreckten Hang ruhig werden, dann loslassen.

## Sauber, wenn
Das Kinn bleibt bei der Seitwärtsbewegung über der Stange.

## Technik
- Eine Wiederholung ist einmal links und einmal rechts.

## Atmung
Oben in der Mitte kurz einatmen, beim Seitwärtsschieben ausatmen.

## Häufige Fehler
- Der Körper sinkt beim Seitwechsel ab.
  → Nur so weit zur Seite, wie du die Höhe halten kannst.
- Die Beine schwingen mit.
  → Beine geschlossen, Bauch fest.

## Leichter und schwerer
Leichter: nur eine kurze Strecke zur Seite schieben oder Archer Pull-up. Schwerer: an jeder Seite 2 Sekunden halten.

## Wann aufhören
Aufhören, wenn das Kinn unter die Stange sinkt oder ein Ellbogen schmerzt.

## Trainiert
Rücken, Bizeps, einseitige Kraft
